Windows and Steam games on Apple Silicon

Vodka is a native SwiftUI application that creates Wine bottles, installs Steam, and launches games with per-game settings, launcher fixes, and controller support.

Quick start

An Apple Silicon Mac running macOS 15 or later with Xcode 16 or later is required.

# Build, ad-hoc sign and install /Applications/Vodka.app
scripts/install-local.sh

# Run the unit tests
swift test --package-path VodkaKit

Repository layout

Vodka/           SwiftUI application target
VodkaKit/        Swift package for Wine, bottles, Steam, and game database logic
VodkaCmd/        Command-line launch helper for Dock shortcuts
VodkaThumbnail/  Quick Look thumbnail extension for .exe files
scripts/         Build, release, localization, and secret-scan scripts
runtime/         Local runtime build driver and release notes

Vodka downloads its Windows runtime archive at setup time. Read the runtime documentation before building custom Wine archives.
